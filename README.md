# Live Chat CSS

ライブ配信のチャット表示を装飾し、不要な要素を非表示にするためのカスタム CSS です。

非表示にする要素の指定をまとめることで、対象の追加・削除・変更をしやすくしています。配信画面に必要な情報だけを残し、見やすいチャット欄を作るために使用します。

> [!NOTE]
> CSS は対象の要素を画面上で非表示にします。元の HTML やチャットのデータ自体を削除するものではありません。

## 主な目的

- ライブチャットの表示を配信向けに整える
- 配信画面に不要な要素を非表示にする
- 非表示にする対象を追加・削除しやすくする
- サービス側の表示変更にあわせて更新しやすくする

## 導入方法

1. 購入した商品に付属する案内を確認します。
2. 案内に記載された方法でスタイルシートを読み込みます。
3. 配信ソフトやウェブサービスのブラウザソースにチャット画面を追加します。
4. プレビューを表示し、チャットが正しく装飾されていることを確認します。

設定項目の名称や手順は、使用するソフトウェアやサービスによって異なります。詳しくは各サービスのヘルプもあわせて確認してください。
